# 嵌入式 CLI 文档

[English](README.md)

本包包含通过 `mooncram docs --list` 和 `mooncram docs <document-name>`
提供的嵌入文档。这些文档主要面向 mooncram CLI 用户，通常情况下这些用户不会直接阅读mooncram的源码

## 内容原则

文档应帮助 CLI 用户选择命令、编写测试、理解结果或排查失败。
优先描述用户能够通过 CLI 观察和验证的行为：

- 支持的命令、选项、默认值、前置条件和输入语法。
- 路径与工作目录规则、标准输出与标准错误、退出码、诊断信息，以及对文件的修改。
- 可运行的示例，明确说明准备步骤、执行命令和预期结果。
- 影响用户工作流程的限制和边界情况，并提供检查行为或确认修复的方法。

说明用户需要做什么、会看到什么，以及如何验证结果。
示例应明确所需文件、工具和工作目录，避免依赖未说明的仓库环境。
描述当前行为，并与 CLI 的实际表现和测试保持一致。

仅在实现细节有助于解释 CLI 用户关心的行为或结果时，才将其写入嵌入文档。
内部类型、辅助函数、调用流程和架构说明应放在代码注释或开发者文档中，
除非理解用户可观察到的结果确实需要这些信息。

## 文档维护

编辑 [`mdfiles/`](mdfiles/) 中的 Markdown 源文件。
[`moon.pkg`](moon.pkg) 中的嵌入规则会生成对应的 `.mbt` 文件；
应修改源文件，而非生成的副本。主题名称、摘要和嵌入正文在
[`export.mbt`](export.mbt) 中注册。

修改文档时，通过 CLI 验证示例及其描述的结果。
保持主题摘要和相应译文的内容一致。
